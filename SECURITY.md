# Security

Spotted something wrong with nevadacitynugget.com, such as a page that runs code it should not,
a link that goes somewhere unexpected, or a way to tamper with the paper? Write
news@nevadacitynugget.com with "SECURITY" in the subject. Please do not open a public issue.

How the site is kept safe is described under "Security" in [ROADMAP.md](ROADMAP.md).
