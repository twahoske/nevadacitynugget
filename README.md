# Nevada City Nugget

A daily local paper for Nevada City, California — City Hall, the Planning Commission, fire and weather, amusements, the KVMR radio log, and the stars over Deer Creek. Compiled each morning and published at [nevadacitynugget.com](https://nevadacitynugget.com).

- `index.html` — today's edition
- `editions/` — the archive, one file per day
- `sources.html` — sources & methods
- `ads/` — house ads

An independent summary, not an official city publication, and no relation to the historical paper of the same name beyond admiration.
